# Changelog

All notable changes to Lens Log are documented here.

## 1.1.0 — 2026-09-19

Initial public release.

### Highlights

- Offline-first logging of frame number, lens, aperture and X/Y shift
- Durable IndexedDB records and an explicit pending-mutation queue
- Incremental, revision-based synchronisation with a server-side SQLite database
- IMAGE, ALPA and PICO shift-direction conventions
- Built-in and custom lens library with searchable lens selection
- Frame-range search, CSV export and full JSON backup and restore
- Consistent automatic SQLite backups
- Installable PWA with controlled application updates and persistent-storage status
- Responsive phone layouts, automatic night mode, two text sizes and optional axis colours
- Multi-architecture Docker support for AMD64 and ARM64 servers
